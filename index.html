Arquitectura GiraTek Feed

Flujo Autónomo n8n + Gemini AI + Enlaces Verificados + GitHub Pages CDN

1

Cron Trigger en n8n Cada 6 Horas

Un temporizador en n8n inicia la ejecución periódica para consultar los feeds RSS más influyentes (Xataka, TechCrunch, Eurogamer, GitHub Blog).

2

Nodo IA Gemini (LLM Agent) Gemini 2.5 Flash

La IA analiza el contenido, traduce artículos del inglés, genera resúmenes atractivos de 2 párrafos, clasifica por categoría y preserva el enlace directo a la noticia original.

3

Commit Automático a GitHub API PUT /contents/data/noticias.json

n8n realiza una petición HTTP autenticada con un Personal Access Token (PAT) al repositorio King1Angel/tech-news, actualizando el archivo data/noticias.json sin requerir bases de datos externas.

4

GitHub Pages + Client-Side Fetch Costo $0 / CDN Global

Los usuarios reciben una interfaz ultrarrápida que consulta el JSON con timestamp anti-caché. Todo se sirve vía la CDN global de GitHub con latencia mínima y costo de infraestructura cero.
